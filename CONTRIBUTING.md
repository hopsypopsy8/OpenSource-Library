# Contributing

Thanks for helping keep this list useful.

## What belongs here

A project qualifies if it is:

1. **Open source** under an OSI-approved licence (fair-code/source-available projects may be listed only with a clear note).
2. **A replica** of a specific commercial product, game, platform or protocol: a reimplementation, decompilation, recompilation, or a functional alternative people actually use in place of the original.
3. **Real and alive**: public source code, at least one working build or a documented roadmap, and a commit in the last 12 months (classic finished projects excepted).
4. **Clean**: it does not ship copyrighted game data, ROMs, keys, cracked binaries, or tools whose main purpose is piracy or bypassing DRM.

## How to add an entry

- Add a row to the right table, keeping it alphabetical or grouped as the section already is.
- Link to the **official** repository or website, never a fork, mirror, or re-upload.
- Format: `| [Name](link) tags | What it replicates | One short sentence of notes |`
- Use the tags from the legend in the README (🔬 🧬 🔁 🆕 📦).
- In your PR description, include the licence and a source (press coverage, project site) confirming it is the official repo.

## What gets removed

- Repos with no source, only binaries or "download" links.
- Projects that are taken down or abandoned without a usable release.
- Anything flagged as malware or impersonation.

## Reporting a suspicious repo

Open an issue using the **Report a suspicious link** template. Security reports are prioritised.
